# Баг-репорт REDSMS

Трекер баг-репортов для команды: `index.html` (интерфейс) и `server.py` (сервер с общей базой). Нужен только Python 3, сторонних зависимостей нет.

## Возможности

- Форма по шаблону баг-репорта: заголовок, окружение, шаги, ожидаемый и фактический результат, серьёзность, приоритет, воспроизводимость, обходной путь.
- Подсказка похожих багов, пока вы пишете заголовок, — чтобы не заводить дубликаты.
- Статусы: Новый → В работе → Исправлен → Закрыт / Отклонён.
- Фильтры по статусу и серьёзности, поиск по тексту.
- Вложения: скриншоты, видео, логи (до 20 МБ на файл).
- Выгрузка бага в PDF и Markdown (.md) и копирование текста в буфер обмена.
- Создание задачи в Яндекс Трекере: в карточке бага укажите ключ очереди. Откроется форма новой задачи с заполненными заголовком и описанием.
- Общий список для всей команды: изменения коллег появляются у всех в течение 4 секунд.

## Запуск

```bash
python3 server.py --host 0.0.0.0 --port 8501
```

Откройте http://localhost:8501. Сервер отдаёт страницу на любой адрес, поэтому работает из любой рабочей папки и за прокси с префиксом пути.

### Docker

```bash
docker build -t bag-report .
docker run -p 8501:8501 -v bag-report-data:/data bag-report
```

### Хостинг

- Если хостинг собирает по `Dockerfile`, ничего задавать не нужно. Сервер слушает `0.0.0.0` и порт из переменной `PORT`, по умолчанию 8501.
- Если хостинг просит команду запуска:

  ```bash
  python server.py --host 0.0.0.0 --port 8501
  ```

  Порт должен совпадать с полем «Порт приложения».

**Обязательно подключите постоянный диск (volume)** к папке `/data` (в Docker) или к папке из `DATA_DIR`. Без него база будет обнуляться при каждом передеплое.

## Настройки

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `PORT` | Порт, если не указан `--port` | `8501` |
| `DATA_DIR` | Папка с базой `bugs.sqlite3` и вложениями `files/` | `./data` (в Docker — `/data`) |
| `APP_PASSWORD` | Пароль на весь сайт. Без него сайт открыт всем, у кого есть адрес | не задан |
| `APP_USER` | Логин к паролю (необязательно) | не задан |

## Где хранятся данные

| Как открыт | Хранилище |
|---|---|
| Через `server.py` (локально, в Docker, на хостинге) | Общая база SQLite на сервере, в `DATA_DIR` |
| Как артефакт на claude.ai | Общая база артефакта |
| Файлом `index.html` без сервера | `localStorage` браузера: видно только вам |

Резервная копия — это копия папки `DATA_DIR`.
